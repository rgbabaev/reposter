# Project rules

- Follow [the specification](docs/specification.md) and [the implementation plan](docs/implementation-tasks.md).
- Keep documentation and other text files concise.
- Write self-explanatory code following Clean Code practices. Do not add code comments except to explain business entities or domain concepts.
- Maintain the architecture decision journal in `docs/adr/`. Record significant decisions in concise, numbered Markdown files with context, decision, and consequences.
